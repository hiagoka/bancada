# Fontes

- **Clash Grotesk** e **General Sans** (variáveis, 200–700), da Fontshare / Indian Type Foundry, sob a
  ITF Free Font License (FFL) 2.0 (`LICENSE-Fontshare-FFL.txt`). Os `.woff2` são os arquivos oficiais, sem
  modificação (a licença proíbe subsetting e conversão). Hospedadas aqui, sem CDN.
- **JetBrains Mono** vem do pacote `@fontsource-variable/jetbrains-mono` (SIL OFL 1.1).

## ⚠ Antes de tornar o repositório público

A FFL permite uso comercial e **self-host no próprio site** (seção 01), mas **proíbe redistribuir o arquivo de
fonte** por "repositório, biblioteca de fontes, serviço de download" etc. (seção 02). Enquanto o repositório for
privado, os `.woff2` aqui são só o self-host do próprio projeto. Um repositório **público** no GitHub distribui
os arquivos. Antes disso (T21), escolha UMA saída e registre a decisão no ARCHITECTURE.md:

1. tirar os `.woff2` do repositório (e do histórico) e baixá-los no build/deploy a partir da Fontshare; ou
2. trocar por fontes com licença livre de redistribuição (OFL, ex.: via Fontsource).

Origem: https://www.fontshare.com/fonts/clash-grotesk e https://www.fontshare.com/fonts/general-sans
